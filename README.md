# خبير صيانة الهواتف — V7

منصة عربية RTL لصيانة الهواتف، مبنية بواجهة ويب وخادم Node.js وقاعدة SQLite مدمجة. النسخة لا تحتاج حزم npm خارجية، لكنها تتطلب Node.js ‏22.13 أو أحدث لدعم `node:sqlite`.

## محتويات المشروع

- `public/`: الواجهة، لوحة الإدارة، وملفات PWA.
- `server/index.js`: HTTP API، جلسات الإدارة، تحديد المعدل، وممر اختياري للمساعد الذكي.
- `server/db.js`: مخطط SQLite وترحيل الأعمدة وبيانات البداية.
- `server/seed.json`: بيانات أولية ومراجع. عائلات الأجهزة وأوامر ADB الإرشادية ليست ضمان توافق لطراز بعينه.
- `tests/run.js`: اختبارات تكاملية للخادم والصلاحيات والتحقق من البيانات.
- `scripts/backup-db.js`: إنشاء نسخة محلية من قاعدة البيانات بعد إيقاف الخادم.

## التشغيل محليًا أو عبر Termux

```bash
node -v
npm test
export SESSION_SECRET="$(node -e \"console.log(require('crypto').randomBytes(32).toString('hex'))\")"
export ADMIN_EMAIL='admin@example.com'
export ADMIN_PASSWORD='استخدم-كلمة-مرور-فريدة-وطويلة-هنا'
node server/index.js
```

افتح `http://127.0.0.1:3000/`، ثم `/api/health` للتحقق من حالة الخادم، و`/admin/` للوحة الإدارة. لا تستخدم كلمة المرور المثال حرفيًا. في الإنتاج، يبدأ الخادم دون `SESSION_SECRET` بالرفض عمدًا. أزل متغير `ADMIN_PASSWORD` من إعدادات الخدمة بعد إنشاء المدير الأول؛ لا تغيّر كلمة المرور المخزنة في قاعدة البيانات بحذف المتغير وحده.

## الاختبارات

شغّل `npm test`. الاختبارات الحالية (55 اختبارًا) تغطي مسارات API، والمصادقة، وCSRF، والتحقق من البيانات، والمراجعة البشرية، ومحددات المعدل، وسلوك المساعد أمام خدمة وهمية. نجاح الاختبارات لا يثبت توافق كل جهاز أو نجاح الاتصال بمزوّد الذكاء الاصطناعي الحقيقي.

## نشر الاستضافة

- استخدم خدمة تدعم Node.js ‏22.13+.
- أمر البدء: `npm start` أو `node server/index.js`.
- اضبط `SESSION_SECRET` و`ADMIN_EMAIL` و`ADMIN_PASSWORD` من إعدادات البيئة السرية، لا من ملفات الواجهة ولا من Git.
- اضبط `DB_FILE` إلى مسار على قرص دائم مدعوم من الاستضافة. لا تعتمد على نظام ملفات مؤقت لبيانات SQLite.
- اترك `TRUST_PROXY` غير مضبوط افتراضيًا. اضبطه إلى `1` فقط بعد التأكد من أن مزوّد الاستضافة يضبط/ينقّي `X-Forwarded-For` من وكيل موثوق؛ وإلا يمكن تزوير IP وتجاوز حدود المعدل.
- المساعد الذكي اختياري وقد يترتب عليه تكلفة. اضبط `ANTHROPIC_API_KEY` و`ANTHROPIC_MODEL` فقط إذا كنت تملك المفتاح وتحققت من أن اسم النموذج متاح لحسابك. لم يُختبر هذا الإصدار مع الخدمة الحقيقية؛ الاختبار آلي عبر خدمة وهمية.
- خطط الاستضافة المجانية قد توقف الخدمة أو لا توفر قرصًا دائمًا. اختبر إعادة التشغيل واستعادة قاعدة البيانات قبل وضع بيانات حقيقية.

## نسخة احتياطية

أوقف الخادم أولًا، ثم نفّذ:

```bash
npm run backup
```

يمكن تعيين مسار قاعدة البيانات عبر `DB_FILE`. تُحفظ النسخة في `backups/` وهي مستبعدة من Git. انقل نسخة ثانية إلى مكان آمن خارج جهاز الاستضافة، واختبر الاستعادة دوريًا. هذا السكربت لا يرفع النسخة تلقائيًا إلى أي خدمة سحابية.

## الأمان وحدود الاستخدام

- كلمة مرور المدير تُخزّن بتجزئة scrypt مع ملح، وملف تعريف الارتباط `HttpOnly` و`SameSite=Strict` وتوقيع HMAC.
- توجد حدود لمحاولات الدخول حسب عنوان IP وحسب الحساب، ولطلبات المساعد. محددات المعدل في الذاكرة؛ لا تتشارك بين عدة نسخ من الخادم ولا تغني عن حماية على مستوى الوكيل/الاستضافة.
- التحقق من السجلات يتضمن الحقول المطلوبة، وHTTPS للمصادر، وصحة التاريخ، ووجود معرّفات المصادر قبل قبول وسم «موثّق».
- اقتراحات المحتوى لا تُنشر تلقائيًا؛ يتطلب الاعتماد مراجعة بشرية. سجل التدقيق داخلي.
- التحقق من أن الرابط HTTPS لا يثبت أن المحتوى موثوق أو أن الرابط لا يتغير؛ راجع المصادر بنفسك قبل وسم أي سجل بأنه موثّق.
- الواجهة متصلة بالخادم تُزامن بيانات الشركات والموديلات والأعطال والأكواد والأوامر والمصادر من API. في وضع الصفحة الثابتة دون خادم تستخدم البيانات المضمّنة فقط، ولا تعمل لوحة الإدارة أو المساعد الخادمي.
- لا ينفّذ المتصفح أوامر ADB/Fastboot على الهاتف؛ يعرض الأوامر لنسخها إلى بيئة موثوقة فقط. لا تستخدم الأوامر التي تمسح البيانات أو تفتح محمّل الإقلاع إلا بعد فهم المخاطر والنسخ الاحتياطي.
- لا يُدّعى أن قاعدة الموديلات كاملة أو أن جميع الأكواد تعمل على جميع الأجهزة. المحتوى الإرشادي لم يُختبر على كل موديل فعليًا.
- Service Worker يخزّن غلاف التطبيق فقط ولا يخزّن API أو لوحة الإدارة. تغيير الإصدار في `public/sw.js` يزيل الكاش القديم عند التفعيل.

## المتغيرات الاختيارية

راجع `.env.example`. لا ترفع ملف `.env` أو قاعدة البيانات أو مفاتيح API إلى مستودع عام. حافظ على المستودع الخاص حتى تراجع الملفات وتزيل أي بيانات شخصية.
